# data/

- `reviews.csv` — a small illustrative sample (~20 rows, `review,sentiment`
  columns) so the training notebook runs end-to-end out of the box. Swap
  in the Kaggle "Women's E-Commerce Clothing Reviews" dataset (or similar)
  for real training — same column schema, just more rows.
- `intents.json` — 20 sample FAQ intents for the chatbot (greeting,
  order_status, return_policy, shipping_time, etc). Extend this with
  intents specific to your business.
